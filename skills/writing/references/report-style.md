# Report style

GOV.UK and GDS house style for anything read cold: reports, research write-ups, guidance, documentation, announcements, summaries. It adds layout and number rules to the `writing` skill. Start from what the reader needs to know to do or decide something.

- Headings: front-load them, keep them under about 65 characters, make them unique and descriptive. No full stop, dash, slash or question mark.
- Bullet points: introduce the list with a lead-in line that ends in a colon. Start each bullet lowercase. Keep each to one idea. No "and" or "or" after each item, no semicolons, no full stop after the last bullet unless a bullet is itself a full sentence.
- Numbered steps: use a numbered list only for a sequence the reader follows in order. Steps are full sentences and end with a full stop. No lead-in colon needed.
- Links: use descriptive link text that says where the link goes. Never write "click here" or "read more".
- Do not use FAQs, exclamation marks, or all caps for emphasis.
- Do not use Latin abbreviations. Write "for example" not "eg", "that is" not "ie", and "and so on" or "such as" not "etc".
- Write "and", not "&", except in a registered name or logo.
- Use single quotation marks for the titles of schemes or documents.
- Write "disabled people", not "the disabled". Use "they", "them" and "their" rather than gendered pronouns.
